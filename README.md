# Brew Tracker

A small, offline-capable web app for homebrewers: recipes, malt bill, water profile,
water-salt suggestions (with adjustable amounts and live pH/ion feedback) and a guided
mash with temperature, pH and gravity targets. All data stays in your own browser
(use Export / Import to move recipes between devices).

No build step and no dependencies: open `index.html`, or host the folder on any static host.
